# Knowledge base

- `rules/` — constraints to follow. One short file each, with the reason.
- `patterns/` — reusable solutions distilled from retros.
- `prompts/dev/` — reusable prompts for the E→P→A→V cycle.
- `checklists/` — step lists for checks that need a person or a device (Safari, iPhone, screen reader).
- `retros/` — one file per ticket: what was done, plus a Backlog of unverified or deferred items.

Load these during `/evaluate`. Add a pattern when a retro's lesson applies to more than one ticket.
