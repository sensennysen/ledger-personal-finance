# LED-139 · Budgets 4b: summary tiles, Needs attention, table, add from last cycle — retro (2026-09-25)

## What shipped
- `lib/budgetHistory.ts`: the history loop lifted out of `useBudgets` (`buildBudgetHistory`), plus `replayCarriedIn`. `useBudgets` now attaches `period_spends` (every closed period's spend), so the budget form replays Carried in with the amount and switch as edited. `tests/budgetHistory.test.mjs` keeps the old loop verbatim as a reference and asserts identical output in every mode.
- `lib/budgetSummary.ts`: `summarizeBudgets` (monthly budgets in the default currency; the rest are counted and named as not included), `sortByUsage`, `needsAttention`, `cycleDaysLeft`.
- `lib/budgetSuggestions.ts`: `spendByCategory`, `lastCycleCandidates`. `useBudgets` exposes `previousCycle` (last cycle's expense rows, tied to the requested cycle) and `createBudgets` (one array insert, all or nothing).
- UI (`components/budgets/`): four tiles from `sm` up and a "Remaining" hero on a phone; a Needs attention block; a table sorted by % used from `md` up with the card list below it, sharing one `DeleteBudgetButton` (a failed delete is now a notification, not a `console.error`); "Add from last cycle" with a confirmation dialog.
- One visible title on a phone (the page's own h1 is `sr-only`; the shell shows "Budgets"). `Progress` no longer leaks base-ui's hidden "x" into `innerText` (`[&>span[role=presentation]]:hidden` on the root).

## Decisions
- **"Copy last cycle" became "Add from last cycle"** (your call). A budget is one recurring row with no per-cycle copies (`end_date` is unused), so there is nothing to copy. The button adds monthly budgets for categories spent in last cycle that have none, at that spend rounded up, with `start_date` at last cycle's start. See `rules/budget-is-one-recurring-row.md`.
- **Needs attention uses `--warning-container`**, not a new `--gold-container`: the tint already exists and is contrast-tested (a foreground pair was added). The design's #FBF4E8 is still unused.
- **Tiles cover monthly budgets in the profile currency**; a note says what is left out.
- The mobile row of cards is the old card, unchanged, just sorted.
