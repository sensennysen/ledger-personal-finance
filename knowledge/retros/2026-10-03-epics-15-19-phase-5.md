## What went well
- **Decisions were made with numbers.** The sweep measured LED-202 before any code changed, which showed the decided fix could not meet its criterion. The owner chose a new course from the measurements.
- **Checking the page against the code found a bug.** The deletion page said everything is erased, but receipt files outlived the account. The fix shipped before the wording that relies on it, and it was proven on a local stack (2 files left before, 0 after).
- **The first measurements caught their own mistakes.** The sweep's first run reported hover states as failures. The script now parks the pointer, and the real hover issue is LED-246.
- **Drift is now a CI failure.** A new CSP host or browser storage key without its legal-page line fails `legalPages.test.mjs`. This was checked by removing one key, which made the test fail.

## What to change
- **Measure a decided fix against its acceptance criterion before building it.** OD-11 (a) was chosen from LED-145's numbers, which used the old widget order. Under LED-134's default, the chart was sixth. A two-minute `--home-fold` run would have shown that before the decision.
- **A column that every write sends needs migrate-then-deploy.** `rules/schema-changes-via-migrations.md` now says so: LED-185 and LED-232 both depend on it.
- **Park the pointer before a rendered scan.** Added to `patterns/rendered-contrast-scan.md`.
