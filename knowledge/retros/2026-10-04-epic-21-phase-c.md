## What went well
- **Capping the range end, not filtering rows, kept each site to one line.** `countedEnd(end, today)` is a no-op for a closed cycle, which is AC (c) for free. The like-for-like current window is the same range, so the two tickets agree without sharing code.
- **SQL first, then the screen.** Computing the expected figures before opening the browser made each check a comparison, not a reading.

## What to change
- **Check test arithmetic against the rollover rules before blaming code.** One new Overspending test failed because the fixture's August left a surplus. The code was right.
