# LED-179 · Screen-reader pass via the accessibility tree — retro (2026-10-05)

Branch `main`. Read what a screen reader is given on each LED-179 surface from the browser's accessibility tree, and fix what fails. This replaces the 2026-09-29 static read (`2026-09-29-live-sweep-screenreader.md`).

## Method
Browser pane (Chromium), local Supabase, demo user, 1024 and 1440 wide. Real key presses for Tab, Enter, arrows and Escape. Failures were forced by patching `fetch` in the page and stubbing `navigator.onLine`; no request reached the database (0 probe rows after).
