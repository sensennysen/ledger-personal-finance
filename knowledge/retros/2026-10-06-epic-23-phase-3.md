## LED-290: the 400
- **Request:** `POST http://127.0.0.1:54321/auth/v1/token?grant_type=refresh_token`, started by supabase-js `_handleRequest`.
- **Response:** 400 `{"code":"validation_failed","message":"Refresh token is not valid"}`.
- **Cause:** the browser holds a session (`sb-127-auth-token`) that the server no longer accepts, for example after a local database reset or a sign-out elsewhere. supabase-js tries to refresh it, drops it, and the page stays on `/login`.
- **Reproduced** in a clean headless Chrome over CDP, with a stale session injected. A fresh profile with no stored session loads `/login` with no 4xx at all.
- **Not fixable on the client:** the browser logs every 4xx, and the refresh is the only way to learn the token is dead. Expected.
- **Production:** `https://ledger-personal.vercel.app/login`, signed out, had no console messages and no response ≥400.
