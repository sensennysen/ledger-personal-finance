# QA fixes — 2026-10-06

Fixed the five findings from the [local E2E QA](2026-10-06-e2e-qa.md) on branch `qa-fixes`. See the [fix run](../../docs/qa/runs/QA-20261006-fixes/report.md).

- **QA-001 (P1):** the importer read direction from the amount's sign, but Ledger exports positive amounts with an explicit Type. Ledger exports are now a recognised format, and direction comes from Type. Anything the importer cannot represent safely (transfers, a bad Type, a negative amount, another currency, an export missing Type or Currency) blocks the import rather than being guessed. F-019c retested in the browser: −7, not +7.
- **QA-002:** `FormControl` now behaves as a slot, so the label, error and description reach the real control. Controls nested inside wrappers were moved, and the custom controls forward the props.
- **QA-003, QA-004, QA-005:** added a Not Found route, filter-aware empty text, and `fileURLToPath` in two tests.

Lint, build and `pnpm test` (1,126 tests plus redesign checks) pass on macOS.

## Lessons

- A test that checks only that rows persist (F-019a) can pass while the financial meaning is wrong. Import tests must assert direction and balance.
- Running `FormControl` on a wrapper looked correct in the markup but broke every label. A test should check `label[for]` against the element's tag, not just that the id exists.
