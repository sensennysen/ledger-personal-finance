Ledger — Redesign Proposal

Navigation & UX redesign, executed as real Material 3

The current build applies M3 colors on top of the old structure — a floating rounded nav bar, a dialog stretched into a bottom sheet, plain bordered inputs — which is why it reads as a reskin rather than a Material app. This pass fixes the structure: correct tonal surfaces and shape scale, a clearer 5-destination navigation model, and — the concrete bug fix — a dedicated full-screen flow for adding a transaction instead of a dialog fighting the mobile keyboard.

Flat bottom nav, no floating card Full-screen add-transaction — no dialog/keyboard fight Reports promoted; Categories & Settings are secondary screens Outlined text fields, full-pill buttons, real state layers
