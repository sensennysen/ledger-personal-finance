Ledger · Material Design 3 · Desktop
Desktop — persistent navigation, split view, keyboard-first
The mobile IA holds, but desktop stops hiding it: the five destinations live in a permanent navigation drawer, the breadcrumb is always addressable, and detail opens beside the list instead of replacing it. Both themes below share one token set.
Semantic transaction colors
Gold stays the brand and interaction color; it never encodes money. Direction is carried by three dedicated hues, applied to the type chip, the amount, and any delta indicator — so a row's kind is legible before the label is read. Color is always paired with a sign or arrow, never the only cue.
